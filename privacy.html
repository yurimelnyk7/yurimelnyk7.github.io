Privacy Policy

Melnik Studio Uploader is a private tool used solely by its owner (Yurii Melnyk, yurimelnyk@gmail.com) to upload videos to and read statistics of the owner's own YouTube channel.

Data accessed

With the owner's consent the app uses the YouTube Data API and YouTube Analytics API to upload videos, set titles, descriptions and thumbnails, and read channel and video statistics.

Storage and sharing

OAuth tokens are stored only on the owner's local computer. No data is sold, shared with or transferred to third parties. The app does not access data of any other users.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

This app uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
